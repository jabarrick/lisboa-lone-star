## 写手 W10：圣鲁伊斯镇民（文件 `story/p1.js`，前缀 `p1_`）

家乡小镇现在的常驻人物大多是恋爱对象。请让小镇本身活起来：
1. **5–6 位新镇民**，加入 `NPCS`（`loc` 用家乡地点 id：`main`、`bar`、`church`、`college`、`ranch`、`gym`、`shop` 之一；不要 beats/meet/romance）。例如：五金店老板（镇议员之一，第二章投票里出现过“五金店老板”）、退休历史老师（也是议员）、县图书馆管理员、开拖车公园的寡妇、越战老兵协会的会长、在店里打零工的高中毕业生……
2. 每人一条 **4 段连续情节**，在家乡的地点里推进：用 `EXTRA_LOCS.push({id:'p1_xxx', n:t(...), open:()=>..., acts:[...]})` 新增 2–3 个家乡地点（五金店、县图书馆、退伍军人会所、拖车公园……），或在已有地点的行动里推进。每段之间要隔几周（用 `S.week` 判断），情节完成给持久奖励（`grantPerk`、学菜、口碑、属性、和老角色的关系）。
3. **8–10 个小镇事件**（`STORY.push`，分布在第 5–46 周，避开已有事件所在的时段——见各 `c*.js` 的 `when`），比如镇上停水、高中毕业典礼、县集市评比、龙卷风警报夜、镇长选举、教堂义卖……要和新镇民、老角色交织。
4. 至少两位新镇民与主线（罐头厂、特拉维斯、若泽）有交叉，并且他们的结局能影响第四章：可设 `S.flags.p1_councilVote=1`（某位议员倒向你）、`S.flags.p1_festHelp=1`（帮忙办节）。

## 写手 W11：主要角色的深层故事（文件 `story/p2.js`，前缀 `p2_`）

给已有的重要配角各加一条有分量的支线（每条 3–4 个 `STORY` 事件，分布在全年，带选择与后果）：
1. **弟弟鲁伊来德州**（约第 33–35 周，取决于你寄过多少钱 `S.flags.sentMoney` 和你给他打过多少电话）：他看见你在这里的生活；兄弟间关于母亲、外公、若泽的谈话；他会不会也想留下。
2. **特拉维斯·博伊德的另一面**：他父亲汉克的阴影、他自己欠的债、他和罗兹的关系；在第四章选“交易”路线时，给他一次被说服或彻底变坏的分歧（读 `S.flags.travisDeal`）。
3. **厄尔要卖酒吧**：健康、乔琳、他和若泽的往事；你可以帮他、买下来（大笔钱的去处）、或说服乔琳留下。
4. **阿尔贝蒂娜太太的八十岁生日**：亚速尔老乡们、1958 年的船、她想在死前再听一次亚速尔的歌。
5. **汤米和小戴尔长大**：高中最后一年、橄榄球、离开小镇还是留下、戴尔牧师与儿子的冲突。
可以再加 1–2 条你觉得最有戏的（例如格蕾丝的过去、贝托和露西娅牧场的旱灾）。
