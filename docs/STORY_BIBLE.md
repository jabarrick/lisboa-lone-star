# 《里斯本·孤星》剧情总纲 v1.0（写手必读）

游戏是单文件 HTML 叙事经营游戏。现有引擎、人物、第一章事件都在
`/home/claude/lisboa-game/lisboa/template.html`
（`<script>` 里搜索 `const NPCS=`、`const EVENTS=`、`function yearEnd`）。动笔前先通读 NPCS 和 EVENTS，保持人物声音一致。

目标：剧情总量扩到原来的 6 倍。原来的剧情约 5,000 个汉字；扩完后约 30,000 字。每位写手负责约 4,000–5,000 个汉字的新叙事（不含英文和葡语），全部三语。

## 1. 一句话与主题

28 岁的里斯本青年蒂亚戈（玩家可改名，代码里用 `S.name`）继承了舅舅若泽在德州小城圣鲁伊斯的葡萄牙烧烤店，必须亲自经营满 48 周。一年里他要回答三个问题：
1. **魅力是资本还是枷锁？**（脸、口音、肌肉都能开门，但信任只能靠真话）
2. **乡愁对抗融入**：留下多少里斯本，变成多少德州？
3. **舅舅为什么离开、又为什么从不回家？**——贯穿全年的悬念，由若泽的 12 封未寄出的信逐步揭开。

语气：温暖、自嘲、不煽情；文化冲突写成喜剧，每章留一处安静的苦涩。主角内心独白用第二人称“你”。

## 2. 世界

- **圣鲁伊斯（San Luís）**：虚构小城，人口约 9,000，I-35 州际公路旁，奥斯汀与韦科之间。牧场、油田服务业、社区大学，一座去年刚关闭的罐头厂。五十年代来的亚速尔群岛葡裔老移民，大多不会说葡语了。
- **若泽烧烤店（Zé's Churrasco）**：主角的店和家（楼上小房间）。店后有一块空地，是全剧的关键。
- **其他地点**：主街、孤星酒吧（厄尔的）、铁马健身房、雷耶斯牧场、社区大学、圣安东尼教堂、废弃的“圣鲁伊斯罐头厂”（San Luís Packing Co.）、奥斯汀（远景）。

## 3. 核心悬念：若泽、罐头厂与特拉维斯

**若泽的过去（12 封信逐步揭开）**
- 若泽是主角母亲费尔南达（Fernanda）的哥哥，1996 年离开里斯本。外公的渔船“圣安东尼号”在一次风暴里沉了，欠下债。外公把责任推给当晚掌舵的若泽，若泽背了骂名出走，再没回去。真相：那晚是外公坚持出海，若泽是为了救人才弃船。
- 若泽在罐头厂干了十年，组织工人要求改善条件，并发现厂主汉克·博伊德（Hank Boyd，特拉维斯的父亲）把加工废水偷偷排进地下。1998 年他被解雇。厂方为了让他闭嘴，把厂区边上一小块地（就是现在店后的空地）作为和解给了他，附带一份保密协议。若泽用这块地开了烧烤店。
- 他保留了一份当年的水质检测报告和和解协议副本，藏在罐头厂旧更衣室的铁柜里（第三章结尾找到）。
- 信是写给妹妹费尔南达的，从没寄出：他觉得自己不配被原谅。第 12 封信也写给了外甥。

**特拉维斯的阴谋**
- 特拉维斯·博伊德通过空壳公司（Lone Star Sand LLC）悄悄买下了关闭的罐头厂地块，想改成压裂砂中转站。州里计划在 I-35 修一条新匝道，但罐头厂地块唯一能接上辅路的通道，正好穿过若泽店后那块空地。
- 地块一旦开发就要做环境评估，当年的污染会曝光，所以他要的是：买下若泽的地、拿到那份保密协议的原件、让旧报告永远消失。
- 罗兹（他的工程师）知道部分内情；科琳（记者）的祖父老菲茨杰拉德是罐头厂最后一任工头，知道若泽的事。

## 6. 三语规范

- 每段文字都用 `t('中文','English','Português')`，三个参数都不能空。
- 葡语用**欧洲葡语（pt-PT）**：autocarro、telemóvel、ementa、pequeno-almoço、rapariga、«书名号式引号»；第二人称用 “tu”。
- 英语自然口语，人物有德州味（y'all、fixin' to、Lord、darlin'）。英语里葡语词要么译掉要么一看就懂（“custard tart”，不是 “pastel de nata”），saudade 可以保留但写成 homesickness 更好。
- 中文用 “” 引号；葡语用 «»；英语用 ""。字符串用单引号包起来时，里面的英文撇号要写成 `\'`。

## 7. 代码接口（只写数据，不改引擎）

每位写手只写一个文件：`/home/claude/lisboa-game/story/<你的文件名>.js`。文件内容是普通 JavaScript，直接被插进游戏脚本里运行。可用：

- `STORY.push({id, when, run}, ...)`：事件。`id` 全局唯一，用你的前缀（`c1_`、`c2_`、`c3_`、`c4_`、`rE_`、`rF_`）。`when: ()=>布尔`，每个时段结束后检查一次，每个事件只触发一次。`run: ()=>场景`。
- 场景对象：`{title, meta, text:[段落...], choices:[{t, req, fx, next}]}`
  - `title`、`meta`、`text` 里的每段、`choices[].t` 都必须是 `t(...)` 的返回值（可以拼接 `${S.name}` 或数字）。
  - `req: ()=> true 或 一个字符串（说明为什么不能选）`。常用 `CHARM_REQ(55)`、`MONEY(200)`、`()=>S.stats.oficio>=40||NEED(t('手艺 40','Craft 40','Ofício 40'))`。
  - `fx: ()=>{...}`：效果。`next`：后续场景对象或返回场景的函数（用函数，这样文字随状态变化）。
  - `say(title, text或[段落], meta)`：快捷生成只有“继续”按钮的场景。
- 状态与工具：
  - `S.week S.day S.slot S.cash S.rep(口碑) S.online(线上评分) S.flags(对象，自由使用，用你的前缀命名私有标记) S.letters S.settled S.muscle S.accent('浓'|'中'|'淡') S.course.drive/ride/gun(0–3) S.staff S.menu S.fusion.unlocked S.name`
  - `stat('charme'|'oficio'|'tex'|'saud', 数值)`；`addLike(id, n)`；`addTrust(id, n)`；`rel(id)` → `{met, like, trust, talks, truth}`（0–10）；`charm()`；`formalPenalty()`（浓 −15 / 中 −5 / 淡 +5，用于正式场合判定）；`faceWord()`（“靠脸/靠身材”按钮前缀）；`flirt()`（用了魅力捷径时调用，记轻浮计数）。
  - `log('中','EN','PT')` 写日志；`letter(n)` 记录找到第 n 封信；`meetScene(id)` 返回让某人登场的场景；`NM(id)` 全名、`SH(id)` 简称（会自动按语言切换）；`pick(数组)`；`R(a,b)` 随机数。
  - 改钱：`S.cash += 100`；口碑：`S.rep += 3`。
  - 人物 id：lucia jolene savannah clara hannah brooke megan colleen wade ashley ines roz kyle delphine grace maya earl albertina dale travis beto marisol。
- 恋爱扩展（只有写手 E、F）：
  ```js
  Object.assign(ROMX,{ lucia:{ beats:[t(...),t(...),t(...),t(...)], epilogue:t(...) }, ... });
  ```
  注意：beats 用 `[中,英,葡]` 三元数组也可以，但统一用 `t()` 更好——两种都支持。
- 结局补充（只有写手 D）：`ENDING_EXTRA = (choice) => [ t(...), ... ];`

**节奏规则**
- `when` 里写清楚周数、星期、时段，例如 `()=>S.week===14&&S.day===3&&S.slot===2`。条件型事件加周数下限和必要的 `rel(id).met` 判断。
- 每周最多 1–2 个主线事件，别和已有事件同一时段撞车（已有事件时间见第 4 节）。
- 每个有分量的场景给 2–4 个选择，选择要有不同后果（属性、关系、标记、钱），不要只有“继续”。至少四分之一的选择被属性/条件锁住，让不同玩法看到不同内容。
- 章末事件必须写好，不能依赖随机。
