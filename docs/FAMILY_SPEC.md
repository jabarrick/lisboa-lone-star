先读 `/home/claude/lisboa-game/STORY_BIBLE.md`（人物中文名、三语规范、代码接口、自检方法都在那里，全部照旧）。
游戏引擎：`/home/claude/lisboa-game/lisboa/template.html`；已写好的剧情：`/home/claude/lisboa-game/story/*.js`（尤其 `c4.js` 的圣安东尼节和 `rE.js`、`rF.js` 的恋爱线）。所有路径都在 `/home/claude/lisboa-game/` 下，**不要用 /tmp 下的任何旧目录**。

## 1. 玩家要经历的家庭线

前提：玩家和某位恋爱对象“定下来”（`S.settled === id`，信任 ≥ 8 时在对话里选择）。

1. **留美身份的伏笔（主年内）**：蒂亚戈持 **E-2 条约投资者签证**（葡萄牙是美国 E-2 条约国），身份绑定在经营这家店上——店倒了或卖了，签证就没了。律师格蕾丝在第一章末或第二章初讲清楚这一点。
2. **求婚（第 38 周以后）**：定下来且信任 ≥ 8 时，一场求婚事件。可以选择怎么求（葡式：在阿尔法马式的灯串下唱法多；德州式：牧场日落、马背上；店里：把戒指藏进蛋挞……），对方用自己的话回答（`PARTNER[id].yes`）。也可以选择“还不急”。设 `S.flags.engaged = true`。
3. **筹备婚礼（第 40–47 周）**：母亲费尔南达能不能飞来、婚礼办成葡式还是德州式还是混合、找谁证婚（戴尔牧师 / 教堂神父 / 厄尔）、德州结婚证（县书记官处申请，领证后要等 72 小时）。
4. **圣安东尼婚礼（第 48 周周日）**：里斯本每年在圣安东尼节前后为新人集体办婚礼（“圣安东尼新娘”），圣安东尼是媒人圣徒。小城的节日上办一场婚礼，用到 `PARTNER[id].vow`。设 `S.flags.married = true`，`S.flags.weddingStyle = 'luso'|'tex'|'mixed'`。如果节日没办成（`S.flags.festival === false`），婚礼仍可在教堂或店里办，但更小。
5. **一周年之后（第五章「家 Lar」）**：玩家在一周年选“留下”且已定下来时进入。不再按周推进，而是按“几个月后 / 第二年春天”这样的时间跳跃，20–28 个场景，每个场景 2–4 个选择。内容：
   - **绿卡**：和美国公民结婚 → 递交 I-130 和 I-485（调整身份），在圣安东尼奥的移民局办公室面谈；结婚不满两年，先拿**两年期有条件绿卡**，之后递 I-751 取消条件；婚后三年可申请入籍（N-400）。面谈时官员会问很细的问题（对方牙刷是什么颜色），说实话、拿出真实生活的证据（店里的照片、共同账户）才能过；可以写一段特拉维斯的律师写匿名信举报“假结婚”的插曲，用真相化解。**伊内丝是葡萄牙公民**（`PARTNER.ines.citizen === false`），她走的是 E-2 配偶身份，不是绿卡——写她的版本时要不同。
   - **孩子**：`PARTNER[id].carry` 为真时可以怀孕生子；为假时（韦德、凯尔）走德州寄养转收养；任何伴侣也都可以选择收养或“再等等”。孕期小事件（孕吐、去奥斯汀做检查、汉娜医生——如果她不是伴侣）、出生那一夜（暴雨 / 店里打烊后 / 节日当天）、起名（葡语名 / 英语名 / 两个都要，比如“若泽”纪念舅舅；玩家先选男孩或女孩，或收养时孩子已有名字）。设 `S.flags.child = {name:t(...), sex:'boy'|'girl'}`。用到 `PARTNER[id].baby`。
   - **家**：在圣安东尼教堂受洗（阿尔贝蒂娜太太当教母）、孩子第一句话是葡语、英语还是德州话、店的扩张或保持小店、第一次带全家回里斯本见外婆、入籍宣誓（双重国籍：美国和葡萄牙都允许；孩子在美国出生自动是美国公民，并可在葡萄牙领事馆登记为葡萄牙公民）。
   - 最后一个场景用到 `PARTNER[id].home`，然后进入游戏原有的最终结局。

所有移民流程写成游戏情节，不要写成法律建议；数字和表格编号用上面给的，不要自己编别的。

## 2. 代码接口（在 STORY_BIBLE 的接口之外新增的）

- `PARTNER[id]`：每位恋爱对象一条，已由 `story/f0.js` 建好 `{citizen, carry}`。写手 P 往里填 `yes / vow / baby / home` 四段 `t()` 文字。
- `CH5 = (finalScene) => 场景`：写手 M 定义。它返回第五章第一个场景；整条链最后一个选择的 `next` 必须是 `finalScene`（一个函数，原样传下去：`next: finalScene`）。链里每个场景都要能走到底，不能有所有选择都被锁住的死胡同。进入时 `S.settled` 一定有值，`S.flags.married` 可能为假（没办婚礼）——那就在第五章开头补上求婚/婚礼。
- `FAMILY_EXTRA = (choice) => [t(...), ...]`：写手 M 定义，一周年结局里追加的家庭段落。`choice` 为 `'stay'|'home'|'austin'`。`'stay'` 且有孩子时写一两句“多年以后”的家庭画面；`'home'`/`'austin'` 且有伴侣时写伴侣是否同行；没伴侣返回 `[]`。
- 人物名：`SH(S.settled)` 是伴侣简称（按语言自动切换），`NM(id)` 是全名；孩子名字存成 `t()` 结果，直接拼进文字即可。
- 伴侣性别代词：`tt(NPCS[id].p)` 给出“她/他”“her/him”“ela/ele”。英文主格可自行判断（wade、kyle 用 he，其他用 she）。

## 3. 写手分工

- **写手 M**：`story/f1.js`——主年里的身份伏笔、求婚、筹备、圣安东尼婚礼（STORY 事件，id 前缀 `f1_`），以及 `CH5` 和 `FAMILY_EXTRA`。中文叙事约 6,500–7,500 字。
- **写手 P**：`story/f2.js`——16 位伴侣各自的 `yes / vow / baby / home`（每段 1–3 句，带人物的声音和他们的故事），用 `Object.assign(PARTNER.<id>, {...})`。另外为每位伴侣写一个**婚后专属小事件**，放进 `PARTNER.<id>.moment`，格式是一个返回场景的函数 `()=>({title,meta,text,choices})`（2–3 个选择，最后都只用 `t('继续','Continue','Continuar')` 这样的普通选择，不要 `next`），写手 M 会在第五章中段调用 `PARTNER[S.settled].moment()`。中文叙事约 4,500–5,500 字。

## 4. 自检

```
cd /home/claude/lisboa-game && node validate.js story/*.js
```
它会额外检查 PARTNER 是否齐全、对每位伴侣跑通 CH5（包括随机走完全程是否能到达最终场景），改到 NO PROBLEMS FOUND。写手 M 在写手 P 完成前可能看到 “PARTNER.x missing yes”，这是正常的——只要你自己的部分没报错即可；为了自测，可以临时在自己的文件末尾用 `PARTNER[id].yes=PARTNER[id].yes||t('好。','Yes.','Sim.')` 之类的兜底，但交付前删掉兜底以外的东西——**兜底那一行保留**，这样即使对方漏写也不会崩。
不要修改 template.html、validate.js、build.py、f0.js 或别人的文件。
